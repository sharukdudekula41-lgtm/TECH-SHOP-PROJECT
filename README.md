# 🛒 Tech Shop

A modern and responsive **Tech Shop e-commerce website built with React.js**.
The project provides a simple and interactive shopping experience where users can browse technology products, view product details, add items to the cart, and manage their shopping cart.

## 🚀 Features

* 🏠 Modern Home Page
* 🛍️ Product Listing
* 🔍 Product Search
* 🏷️ Product Categories
* 📦 Product Details
* 🛒 Add to Cart
* ➕ Increase Product Quantity
* ➖ Decrease Product Quantity
* 🗑️ Remove Items from Cart
* 💰 Automatic Cart Total
* ❤️ Wishlist
* 🌙 Dark / Light Mode
* 📱 Responsive Design
* ⚡ Interactive React UI

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/tech-shop.git
```

### 2. Navigate to the Project

```bash
cd tech-shop
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.
